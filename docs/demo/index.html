What this replay proves — and what it does not

The recorder starts the real v2 gateway with local fake iLink, model and DSH services. It checks that three topics receive distinct sessions and that follow-ups are delivered to the original worker session IDs. Topic decisions are deterministic fixtures, so this is not a model-accuracy benchmark or a live WeChat recording. The explanatory captions are generated from verified state; they are not worker replies.

The advisor scene evaluates the existing quota-filter and selection functions with synthetic balances and a fixed Manager response. It verifies candidate filtering and the selected result; it does not invoke real advisors, consume subscriptions, or benchmark task suitability. Tasks in the chat replay run sequentially. Durable scheduling, task-bound mailboxes and a universal Manager entry point remain roadmap work.
