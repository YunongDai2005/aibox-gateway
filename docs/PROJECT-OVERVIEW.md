# AI Box 项目盘点

根据 2026-09-29 的只读检查，AI Box 是把聊天入口、AI 执行器、本地推理与 Linux 工具接到一起的个人 AI 工作站。

| 组成 | 作用 | 本次开源范围 |
| --- | --- | --- |
| AI Box Gateway / wx-router | 微信透明代理、经理、执行调度、话题与交接 | 源码、测试、文档 |
| 用户配套脚本 | 外援管理、额度查询、信箱、通知与检索 | 网关相关脚本 |
| DSH 工作区 | 任务、知识、交接与成果 | 私人数据不发布 |
| AstrBot | 聊天机器人框架和聊天后端 | 第三方项目，不复制 |
| OpenClaw | 通道和工具编排、微信插件宿主 | 作为外部依赖 |
| llama.cpp / 本地模型 | 本机推理与模型运行环境 | 第三方代码和模型不复制 |
| 系统 API / MCP / 状态面板 | 机器操作、状态查看和系统维护 | 本次未导出源码 |

当前最适合独立发布的部分是网关：功能边界清楚，有模块化插件结构和模拟测试。其他机器运维组件尚未纳入本次源码审计。
